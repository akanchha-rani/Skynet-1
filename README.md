# Skynet

Skynet is a **full-stack search engine web application** built using **Node.js, Express, EJS, and MongoDB**.  
The goal of this project is to understand **how real-world search engines work internally**, including query handling, indexing, ranking, and result rendering.

This project focuses on **backend architecture, system design thinking, and extensibility**, making it suitable for **intermediate to advanced full-stack developers**.
